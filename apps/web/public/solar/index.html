In this figure

The panel turns sunlight into current, the controller makes it safe for the battery, the battery stores it, and the load (fan, phone, router) runs from the controller's LOAD and USB outputs. Follow the same order as the real setup, and try mistakes to see what happens.
  1. Battery (fuse out)
  2. Insert fuse → LCD shows 12V
  3. Settings: SLD, LVD 12.0V
  4. Panel
  5. Load
To disconnect, reverse it: Load → Panel → Battery.
